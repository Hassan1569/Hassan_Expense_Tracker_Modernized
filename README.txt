HASSAN EXPENSE TRACKER — MODERNIZED VERSION

1. Create a MySQL database named expense_tracker.
2. Import db_script/expense_tracker.sql.
3. Put the project folder inside XAMPP htdocs or WAMP www.
4. If your MySQL credentials differ, update db_config.php.
5. Open http://localhost/expense_tracker/ (or your folder name).
